# Flask Hello World App

A simple Python Flask application that displays **Hello World**.

## Requirements

- Python 3
- Flask
- Git

## Setup

Clone the repository:

```bash
git clone https://github.com/YOUR_USERNAME/hello-flask.git
cd hello-flask


Create and activate a virtual environment:

Windows
python -m venv venv
venv\Scripts\activate

macOS/Linux
python3 -m venv venv
source venv/bin/activate


Install dependencies:

pip install -r requirements.txt

Run the Application
python app.py


Open your browser and visit:

http://127.0.0.1:5000/


You should see:

Hello World
